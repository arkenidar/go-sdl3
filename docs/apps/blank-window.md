# Blank Window

![Blank Window](../screenshots/blank-window.png)

The bare-minimum starting point for a new app — opens a window, clears it
every frame, and quits on Escape. Nothing else.

This is meant to be copied: duplicate the `cmd/blank-window` directory,
rename the package/binary, and build your own example from there.

## Controls

- Escape or the window's close button: quit

## Run it

- Go installed: `go run ./cmd/blank-window` (from the repo root)
- Windows, no Go needed: double-click `exe/blank-window-start-exe.cmd`
